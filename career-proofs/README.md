# Career proofs

One file per proof. Each proof is a single exceptional, verifiable accomplishment —
the kind of thing that gets pulled into a specialized resume. Nothing here is a
retyped bullet: every claim carries its receipt.

## File convention

```markdown
# Proof: <short title>

## Claim
One line, exact numbers, no adjectives doing the work of evidence.

## Evidence
Where to verify: repo path, receipt file, live system, or demo.

## Verified
Date the claim was last checked against its evidence.

## Used in
Resumes/packs that cite it (update when reused).
```

## Rules

1. A proof without evidence is a draft, not a proof — mark it `status: draft`.
2. Numbers are quoted exactly as they stand. If a number moved, update the
   Verified date; never edit the number without re-checking.
3. Retired or superseded proofs move to `retired/`, never deleted.
4. Nothing invented: no clients, no employers, no metrics without a receipt.
