# GlacierEQ Invention Portfolio V13

V13 rebuilds the recruiter-facing site around Casey Barton’s original systems rather than leading with AKOS, governance doctrine, or Frontier Laws.

## Narrative order

1. Who Casey is
2. What he builds
3. Innovation constellation
4. Three strongest invention stories
5. Interactive repository gallery
6. How the repositories combine
7. Evidence and demonstrations
8. Résumé and role alignment
9. Underlying runtime and governance
10. Frontier Laws
11. Machine-readable interfaces

## Visual system

- 3D recruiter identity card
- problem-centered invention constellation
- animated invention-story diagrams
- filterable repository gallery
- cross-repository workflow maps
- claim-to-proof evidence chain
- role-to-repository evidence map
- compact foundation diagram
- derived-law source map
- machine contract terminal

## Truth boundary

AKOS appears as a supporting foundation, not the narrative center. Public repositories and private architecture are visually and textually distinct. Test counts are scoped to the recorded workstream and do not imply production deployment, scale, customer impact, or hiring outcomes.

## Verify

```bash
npm run check
```

The check validates JavaScript syntax, the exact eleven-section order, the three featured invention stories, route/data contracts, source links, privacy boundaries, and the explicit demotion of AKOS to a foundation-only role.

## Deploy

Use this directory as the Vercel project root. It is a zero-build static site with stable JSON contracts and static rewrites for `/api/health`, `/api/portfolio`, and `/api/runtime`.
