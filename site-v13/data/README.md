# V13 Portfolio Data Contracts

- `portfolio.graph.json` — current human-facing invention graph.
- `flagship-registry.json` — promotion state, evidence, and next gate for the strongest personal systems.
- `company-suites.json` — company-aligned repositories grouped into coherent systems rather than a flat repository wall.

These files are intended to drive visible portfolio depth, machine ingestion, resume selection, and release validation from the same source.
