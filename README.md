## 🏛️ Architecture

The infrastructure stack is a six-service, control-plane-connected system:

```
  xai-colossus-cooling ──┐
  xai-colossus-energy  ──┤
  xai-colossus-security──┤──► colossus-gateway ──► apex-stack (M2A + Aspen)
  xai-colossus-build   ──┘        (routing)         (orchestration + memory)
```

**M2A Protocol** (MCP-to-All): relevance-filtered broadcast routing across all service nodes. Every decision audited. Every event persisted. Built for Colossus-scale coordination.

**Aspen Grove**: persistent semantic memory layer. Agent context survives restarts, redeployments, and failures. Retrieval is semantic — operational history is queryable by meaning, not just by key.
