# AI Ecosystem Company Atlas — hardened static surface

## Architecture

The atlas preserves the production CSP (`script-src 'none'`) and extends the existing semantic-SVG system map instead of replacing it.

- recruiter layer: zero-JS constellation + six domain pages + core donor page
- master layer: `GlacierEQ/job-app-helix` company dossiers
- machine layer: compact JSON snapshot + Protobuf contract
- mesh layer: company → target innovation → reusable donor-system edges

## Truth boundary

- 48 governed baseline tracks: 22 direct company tracks + 25 explicit `NO_DIRECT_EXHIBIT_VERIFIED` tracks + GlacierEQ Core.
- Buildertrend and Lockheed Martin are marked `HYPOTHESIS_PENDING_REGISTRY`; they are not silently promoted into the Aug. 4 baseline.
- Repository breadth and recruiter-admissible proof are displayed separately.
- The wider 1,165+ estate has not yet received complete semantic source inspection.
