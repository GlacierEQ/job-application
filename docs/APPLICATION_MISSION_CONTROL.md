# Application Mission Control

## Mission

Turn Casey Barton's technical work into focused application packets for frontier AI and aerospace companies without exposing the entire internal ecosystem.

## Source of truth

This repository is the public-facing application command center.

Supporting proof-of-work remains distributed across selected repositories, including:

- `GlacierEQ/xai-colossus-cooling`
- `GlacierEQ/xai-colossus-energy`
- `GlacierEQ/xai-colossus-security`
- `GlacierEQ/xai-colossus-build`
- `GlacierEQ/apex-stack`
- `GlacierEQ/colossus-gateway`

## Application packet model

Every company packet contains:

1. one-page company-specific statement
2. resume
3. three to five selected proof-of-work links
4. technical brief
5. demo or walkthrough invitation
6. follow-up message
7. interview talking points

## Company lanes

### xAI
Lead with AI infrastructure, Colossus-inspired systems, memory-aware orchestration, and fast independent execution.

### SpaceX / Starlink
Lead with mission-critical systems, telemetry, reliability, automation, and software that interfaces with physical infrastructure.

### NVIDIA
Lead with AI factories, GPU/HPC infrastructure, data-center systems, orchestration, and platform reliability.

### Anthropic
Lead with reliable agents, memory, evaluation, auditability, restrained systems design, and operational integrity.

## Sharing model

### Public packet

- polished application materials
- selected public repositories
- public architecture diagrams
- concise technical briefs

### Protected packet

- private implementation details
- unreleased architecture
- selected private repositories
- protected Vercel preview

### Live walkthrough

- screen-share demo
- architecture explanation
- selected code walkthrough
- questions and tradeoffs

## Decision rule

Do not send everything.

For each company, select the smallest proof set that demonstrates:

- relevance
- technical depth
- ownership
- execution speed
- judgment

## Operating sequence

1. choose target company and role family
2. select proof-of-work repos
3. generate company statement
4. generate outreach message
5. prepare public packet
6. hold protected assets for follow-up
7. record outreach and next action

## Completion target

The application system is ready when each priority company has:

- tailored statement
- selected repo list
- short technical narrative
- outreach message
- protected demo plan
- interview preparation notes
