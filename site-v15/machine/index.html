INVARIANCE CONTRACT

Presentation may change. Truth may not.

  • evidence and promotion states

FAIL-CLOSED BEHAVIOR

What the machine layer refuses to infer.

Repository names and polished prose are weak evidence. Promotion requires explicit source state and current receipts.

Forbidden inferences

  • company affiliation from company-oriented names
  • production use from repository presence
  • hardware expertise from simulation alone
  • formal leadership from independent systems ownership
  • current certification from historical resume records

Unknown-state policy

  • unknown evidence earns no promotion
  • stale receipts remain stale
  • review is not execution
  • generated tests are not passed tests
  • successful build is not deployment

AGENT ORIENTATION

Use the smallest sufficient contract.

Resume screening begins with resume.json or ats.txt. Technical review follows owning repository links. Portfolio questions use portfolio.json. Company searches use company-families.json. Presentation transformations read psysoc-x-profiles.json and preserve every invariant.
