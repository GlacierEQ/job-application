CAPABILITY ARCHITECTURE · SKILL COMPOSITION

A Mega Skill is a pyramid of real Skills.

Atomic Skills compound into proper reusable workflow Skills. Those compound Skills assemble into a mission-scale Mega Skill: a complete, inspectable, recoverable workflow or pipeline. Every block remains a proper Skill with its own identity, contract, artifact, and validation boundary.

THE HIERARCHICAL UNIT

Complete capability is built upward from validated Skill building blocks.

The human representation is a pyramid. The machine representation is a DAG because one proven lower Skill can legitimately feed more than one compound workflow.

Proper end-to-end workflow / pipeline Skill

Owns mission trigger, durable state, required and conditional workflow selection, recovery, cross-artifact integration, final acceptance, and mission output.

PROPER-SKILL INVARIANT

Composition does not erase Skill identity.

Each level remains independently meaningful and testable. Parents reference child Skill identities and artifacts instead of copying their implementation.

ATOMIC SKILL

Precise procedure

  • independent trigger
  • input/output contract
  • owned method
  • local artifact
  • local validation

COMPOUND SKILL

Reusable workflow

  • independent selection condition
  • ordered child Skill IDs
  • explicit handoffs
  • compound artifact
  • compound acceptance gate

MEGA SKILL

Complete mission pipeline

  • mission-scale trigger
  • required + conditional compound Skills
  • durable state
  • recovery + phase gates
  • integrated mission result
